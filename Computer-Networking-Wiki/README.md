# Computer Networking Wiki

Baza wiedzy z materiałów kursowych uporządkowana jako wiki, a nie jako transkrypcja PDF-ów.

➡️ **Start:** [`docs/index.md`](docs/index.md)  
➡️ **Ścieżka nauki:** [`docs/learning-path.md`](docs/learning-path.md)  
➡️ **Komendy:** [`docs/reference/commands.md`](docs/reference/commands.md)  
➡️ **Laby:** [`docs/labs/index.md`](docs/labs/index.md)

## Struktura

- `docs/` — właściwa baza wiedzy.
- `docs/labs/` — każde laboratorium jako osobna strona.
- `docs/projects/` — projekty integrujące wiedzę.
- `docs/reference/` — komendy, protokoły/porty, słownik, linki i mapa źródeł.
- `_source-archive/` — pełne ekstrakty źródłowe do weryfikacji; **nie są główną wiki**.
- `mkdocs.yml` — opcjonalna konfiguracja do uruchomienia strony dokumentacyjnej przez MkDocs.

## GitHub

Repo działa bez żadnych dodatków: GitHub renderuje wszystkie linkowane pliki Markdown. Jeśli później chcesz wersję „website/wiki”, możesz użyć dołączonego `mkdocs.yml`.
