# Glossary

[← Indeks wiki](../index.md)

| Termin | Znaczenie w materiałach |
|---|---|
| ACL | Access Control List; reguły permit/deny nakładane na interfejs w kierunku in/out. |
| AP | Access Point; łączy klienta bezprzewodowego z siecią. |
| ARP | Address Resolution Protocol; rozwiązuje IPv4 na MAC w lokalnym segmencie. |
| Broadcast domain | Zbiór urządzeń otrzymujących tę samą transmisję broadcast; router rozdziela domeny broadcast. |
| CIDR | Classless Inter-Domain Routing; zapis prefiksu `/n` i adresacja bezklasowa. |
| Collision domain | Obszar, w którym może dojść do kolizji; przełącznik rozdziela domeny kolizji per port. |
| Default gateway | Router używany do ruchu poza lokalną podsieć. |
| DHCP | Dynamic Host Configuration Protocol. |
| DTP | Dynamic Trunking Protocol; negocjowanie trunku na Cisco. |
| FCS | Frame Check Sequence; kontrola błędów ramki. |
| Full duplex | Jednoczesne nadawanie i odbiór. |
| Half duplex | Nadawanie lub odbiór w danej chwili. |
| ICMP | Internet Control Message Protocol. |
| IOS | Cisco Internetwork Operating System. |
| LAN / WAN / MAN / SAN | Typy sieci wg zasięgu/przeznaczenia. |
| LLDP | Link Layer Discovery Protocol. |
| MAC | Fizyczny adres interfejsu; 48 bitów w typowym Ethernet. |
| MTU | Maximum Transmission Unit. |
| NAT | Network Address Translation. |
| NIC | Network Interface Controller/Adapter. |
| OSPF | Open Shortest Path First; link-state IGP. |
| PDU | Protocol Data Unit. |
| RIP | Routing Information Protocol; distance-vector. |
| SVI | Switched Virtual Interface. |
| TCP / UDP | Protokoły warstwy transportowej. |
| TTL | Time To Live; zmniejszany po przejściu przez router, wykorzystywany przez `tracert`. |
| VLAN | Logiczna segmentacja sieci L2. |
| VLSM | Variable Length Subnet Mask. |
| VTY | Wirtualne linie terminalowe Cisco używane m.in. dla SSH/Telnet. |
| WLC | Wireless LAN Controller. |
